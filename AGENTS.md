# Repository Instructions

- After completing requested changes, commit them and push/publish them to GitHub unless the user explicitly asks not to.
- Always publish completed changes to GitHub after committing them, unless the user explicitly asks not to.
- When an APK is produced, bump the Android build version code, name the APK `RainDepartment-v0.0.x-alpha.x.apk`, and publish it in a GitHub pre-release as a release asset, unless the user explicitly asks not to.
- Always build and publish the APK for Android changes: increment `versionCode`, use the `RainDepartment-v0.0.x-alpha.x.apk` filename, and attach it to a GitHub pre-release unless the user explicitly asks not to.
